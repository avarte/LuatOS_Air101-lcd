# 🌡️ DHT11 для LuatOS (ESP32-C3 / Air101)

Чтение данных с датчика температуры и влажности DHT11 с выводом результатов на TFT-дисплей ST7735.

## Описание

Программа считывает данные о температуре и влажности с датчика DHT11 через цифровой интерфейс и отображает их на TFT-дисплее.

## Оборудование

- **Микроконтроллер:** ESP32-C3 / Air101 (LuatOS)
- **Дисплей:** TFT ST7735 (80x160)
- **Датчик:** DHT11 (температура и влажность)

## 🔧 Подключение

| Сигнал | GPIO |
|--------|------|
| DHT11 DATA | GPIO 0 |
| SPI SCK | GPIO 2 |
| SPI MOSI | GPIO 3 |
| TFT CS | GPIO 6 |
| TFT DC | GPIO 10 |
| TFT RST | GPIO 7 |
| Кнопка UP | GPIO 13 |
| Кнопка DOWN | GPIO 8 |
| Кнопка CENTER | GPIO 4 |

## Функционал

- **Чтение температуры** в реальном времени
- **Чтение влажности** в реальном времени
- **Вывод данных** на TFT-дисплей
- **Обновление показаний** по таймеру (2 секунды)

Реализован вывод только изменяемых значений, что уменьшает мерцания медленного дисплея.

## 🎨 Цветовая индикация

| Параметр | Значение |
|--------|----------|
| Температура ≥ 0°C | 🟢 Зелёный (GREEN) |
| Температура < 0°C | 🔵 Синий (BLUE) |
| Влажность | 🔷 Cyan |
| Подписи Temp/Hum | ⚪ Белый |

## Использование

1. Загрузите файлы на устройство
2. Запустите `dht11_test.py`
3. Данные с датчика отобразятся на экране
4. Логи дублируются в UART (консоль)

## ⚠️ Особенности DHT11

- **Медленный датчик** — минимальный интервал между чтениями 2 секунды
- **Точность:** температура ±2°C, влажность ±5%
- **Диапазон:** температура 0..50°C, влажность 20..90%
