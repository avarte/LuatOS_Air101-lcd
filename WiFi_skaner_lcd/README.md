# WiFi_skaner_lcd

связка LuatOS на базе ESP32c3 и модуля Air101-lcd подключенных один к одному

Сканер WiFi сетей с выводом на lcd экран. Вывод осуществляется по 6 строчек. отображается полоса прокрутки. использование джостика позволяет прокручивать список найденых сетей. Цвет названия сети зависит от мощьности сигнала. Использованиы зеленый, желтый и красный цвета.
